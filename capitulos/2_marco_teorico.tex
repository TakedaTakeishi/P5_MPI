\chapter{Marco teórico}

En este capítulo se abordarán los fundamentos necesarios para comprender el uso de MPI y su aplicación dentro del área del cómputo paralelo, así como las herramientas principales utilizadas para el desarrollo y ejecución de programas distribuidos. A lo largo de las diferentes secciones se presentarán conceptos relacionados con el procesamiento paralelo y la comunicación entre procesos, permitiendo establecer una base teórica sobre el funcionamiento de aplicaciones ejecutadas en múltiples nodos o procesadores. Asimismo, se describirá el entorno de trabajo requerido para implementar programas paralelos utilizando OpenMPI en sistemas Linux, considerando aspectos relacionados con instalación, configuración y preparación del entorno de desarrollo para la ejecución correcta de programas en lenguaje C.

De igual manera, el capítulo incluirá la explicación general del flujo utilizado en la creación, compilación y ejecución de programas desarrollados con MPI, mostrando la interacción entre las herramientas necesarias para administrar procesos paralelos y coordinar la comunicación entre ellos. También se presentarán ejemplos prácticos orientados a comprender el comportamiento de aplicaciones distribuidas y la forma en que distintos procesos trabajan simultáneamente para resolver tareas específicas. En conjunto, la información presentada en este capítulo permitirá comprender la relación entre teoría y práctica dentro del cómputo paralelo, además de proporcionar una visión general sobre la utilización de MPI como una de las tecnologías más importantes en sistemas de procesamiento de alto rendimiento.
