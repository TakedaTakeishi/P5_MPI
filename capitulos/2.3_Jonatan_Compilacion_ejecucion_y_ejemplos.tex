\section{Compilación, ejecución y ejemplos en MPI}

En esta sección se abordarán los aspectos prácticos relacionados con la compilación y ejecución de programas escritos en C utilizando la biblioteca MPI. Se explicarán los comandos fundamentales como \texttt{mpicc} para la compilación y \texttt{mpirun} o \texttt{mpiexec} para la ejecución de aplicaciones paralelas. Además, se presentará un ejemplo ilustrativo de un programa de saludos distribuido, que permitirá comprender el flujo completo desde el código fuente hasta la salida en pantalla, destacando las funciones esenciales de MPI involucradas en el proceso.
